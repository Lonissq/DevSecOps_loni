### **Путь изменения**
идея => требования => разработка => CI => тестирование => прод
### **Роли**

| Роли         | Действия                                                          |
| ------------ | ----------------------------------------------------------------- |
| Аналитик     | Формулирует идею и критерии приёмки                               |
| Разработчик  | Создаёт ветку, меняет форму, API и валидацию и пишет автотесты    |
| CI           | Запускает автотесты                                               |
| Тестировщик  | Проверяет приёмку, позитивные/негативные сценарии, регресс и т.п. |
| DevOps       | Деплоит всё это на прод. Настраивает мониторинг, логи и т.п.      |

### **Где может быть ошибка**
Они может быть между новым фронтендом и старым клиентом. Или новым фронтендом и прямым api-запросом
