Номер первой заявки - 5. После пересоздания контейнера заявки сохранились 

API_URL - это настройка, которая говорит веб части, по какому порту обращаться к api
Связь между сервисами настроена через Compose, потому они могут обращаться друг к другу через имена
Внутри сети используется порт 8000. На моей машине связь идёт через порт 8080
Том - это отдельное хранилище, которое просто подключается к контейнеру. Именно поэтому, после пересоздания контейнера, заявки остались

Краткая инструкция:
1. Переходим в директорию, в которой содержатся необходимые файлы ( например compose.yaml )
2. Вводим команду запуска контейнеров - `docker compose -f compose.student.yaml up -d`
3. Переходим по нужному адресу в браузере и проверяем результат

**Защита:** потому что при пересоздании контейнера она обнулится и другие контейнеры не смогут с ней взаимодействовать, если отключён контейнер с томом. Собственно, это и произойдёт
