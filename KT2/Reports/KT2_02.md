**Объяснение** ( писал на основе текущего Dockerfile, так что контекстуально команды могут делать не это, но в данном случае они делает именно это):
- FROM - задаёт базовый образ. То есть мы берём заготовку и используем её
- LABEL - добавляет метаданные в образ. Она же метка
- WORKDIR - создает директорию /app внутри контейнера и делает её текущей рабочей директорией
- ENV - задаёт переменные окружения. В данном случае это два запрета для python
- COPY - копирует файлы с моей машины в текущую рабочую директорию внутри контейнера
- RUN - команды, которые выполняются во время сборки образа
- USER - переключает контекст с root'a на другого пользователя
- EXPOSE 8000 - инфо метка, что контейнер слушает порт 8000
- CMD - команда, которая выполняется при старте контейнера
